Enterprise Distributed Systems Architecture

Engineered for mission-critical low-latency systems requiring strict zero-allocation serialization, predictable tail latency, and autonomous self-healing.

QUIC Multi-Stream Transport

Independent sub-streams per cluster service completely eradicate TCP Head-of-Line blocking. Built-in TLS 1.3 encryption with automatic mutual node authentication.

SWIM Gossip Failure Detection

Scalable O(1) membership protocol with indirect pinging and suspicion-to-dead exponential decay. Quickly isolates partitioned nodes without overwhelming the network.

Embedded Raft Consensus

Native control-plane consensus with automated leader election, write log replication, and compact snapshotting. Zero external dependencies like ZooKeeper or etcd.

Fjall Zero-Copy LSM Storage

Embedded disk-backed Log-Structured Merge-tree storage. Write-optimized write-ahead logging with isolated keyspace partitioning and sub-millisecond point reads.

Planus FlatBuffers Codegen

Automated schema compilation in build.rs via the aaron-build crate. Zero CPU cycles wasted parsing or decoding payloads at runtime.

Embedded Vue 3 Admin UI

Single-binary management dashboard compiled directly into the binary via rust-embed. Real-time topology canvas, keyspace browser, and metric graphs.

Idiomatic Rust API

Build nodes and compose services in a few lines of clean, type-safe async Rust. 

use aaron::{
    admin::{AdminConfig, AdminService},
    membership::{MembershipConfig, MembershipService},
    tracing::TracingService,
    Context, Node, Uuid, service_fn,
};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Configure SWIM gossip membership
    let mem_config = MembershipConfig {
        bind_addr: "127.0.0.1:17946".to_string(),
        seeds: vec!["127.0.0.1:17940".to_string()],
        cluster_id: Some(Uuid::random()),
        probe_interval: std::time::Duration::from_millis(500),
        probe_timeout: std::time::Duration::from_millis(150),
        suspect_timeout: std::time::Duration::from_millis(1000),
        indirect_ping_targets: 3,
        gossip_fanout: 3,
    };
    let (membership, handle) = MembershipService::pair_with_config(mem_config);

    // Start Node with tracing, gossip, and embedded Vue.js admin
    Node::new("worker-node-1")
        .with(TracingService::new())
        .with(membership)
        .with(AdminService::new().with_membership_handle(handle))
        .run()
        .await?;

    Ok(())
}
use aaron::{Context, Node, service_fn};

// Isolated LSM Tree Keyspaces with Write-Ahead Logging
let storage_service = service_fn("order_storage", |ctx: Context| async move {
    let ks = ctx.store.keyspace("orders")?;

    // Sequential write into Fjall LSM Engine
    ks.insert("order:1004", r#"{"id":1004,"amount":99.50,"currency":"USD"}"#)?;
    ctx.store.persist()?;

    // Fast point lookup
    if let Some(bytes) = ks.get("order:1004")? {
        println!("Fetched order payload: {:?}", String::from_utf8_lossy(&bytes));
    }

    Ok(())
});
use aaron::{membership::MembershipEvent, Context};

// Subscribe to real-time cluster membership events via EventHub
let mut sub = ctx.event_hub.subscribe::<MembershipEvent>().await;

tokio::spawn(async move {
    while let Ok(event) = sub.recv().await {
        match event {
            MembershipEvent::MemberJoined { node_id, addr } => {
                println!("Node {node_id} joined at {addr}");
            }
            MembershipEvent::MemberSuspect { node_id } => {
                println!("Node {node_id} is suspect! Probing indirectly...");
            }
            MembershipEvent::MemberDead { node_id } => {
                println!("Node {node_id} declared DEAD");
            }
        }
    }
});
