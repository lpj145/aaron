Developer-First Rust API

Do protótipo minimalista a um cluster distribuído de alta disponibilidade em poucas linhas de código idiomático. 

// Modelo Simples: Crie um nó com armazenamento embutido em segundos
use aaron::{Context, Node, service_fn};

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Inicializa o nó de runtime com um serviço assíncrono leve
    let node = Node::new("order-service")
        .with(service_fn("orders", |ctx: Context| async move {
            // Acessa keyspace isolado no engine Fjall LSM
            let orders = ctx.store.keyspace("orders")?;

            // Gravação com WAL em disco e latência de ~6 microssegundos
            orders.insert("order:1001", br#"{"customer":"alice","amount":99.50}"#)?;
            ctx.store.persist()?;

            // Leitura pontual sub-milissegundo
            if let Some(payload) = orders.get("order:1001")? {
                println!("Pedido gravado: {}", String::from_utf8_lossy(&payload));
            }
            Ok(())
        }));

    println!("Aaron Node pronto para requisições.");
    node.run().await?;
    Ok(())
}
// Modelo Completo: Cluster distribuído com SWIM gossip, Admin UI e EventHub
use aaron::{
    admin::AdminService,
    membership::{MembershipConfig, MembershipEvent, MembershipService},
    tracing::TracingService,
    Context, Node, Uuid,
};
use std::time::Duration;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 1. Configura o protocolo de fofoca (SWIM) e detecção de falhas O(1)
    let mem_cfg = MembershipConfig {
        bind_addr: "0.0.0.0:18100".to_string(),
        seeds: vec!["10.0.0.1:18100".to_string()], // Semente para bootstrap
        cluster_id: Some(Uuid::random()),
        probe_interval: Duration::from_millis(400),
        probe_timeout: Duration::from_millis(150),
        suspect_timeout: Duration::from_millis(1200),
        indirect_ping_targets: 3,
        gossip_fanout: 3,
    };
    let (membership, handle) = MembershipService::pair_with_config(mem_cfg);

    // 2. Compõe o nó com observabilidade, clustering e Admin UI Vue 3 embutido
    let node = Node::new("worker-01")
        .with(TracingService::new())                                // Reload dinâmico de logs
        .with(membership)                                          // Protocolo SWIM sobre QUIC
        .with(AdminService::new().with_membership_handle(handle)); // Console web na porta 28100

    // 3. Reage a eventos do cluster em tempo real (entradas, suspeitas, quedas)
    let mut sub = node.context().event_hub.subscribe::<MembershipEvent>().await;
    tokio::spawn(async move {
        while let Ok(event) = sub.recv().await {
            match event {
                MembershipEvent::MemberJoined { node_id, addr } => {
                    println!("Nó {node_id} ingressou no cluster via {addr}");
                }
                MembershipEvent::MemberSuspect { node_id } => {
                    println!("Nó {node_id} suspeito de falha. Disparando ping indireto...");
                }
                MembershipEvent::MemberDead { node_id } => {
                    println!("Nó {node_id} confirmado MORTO. Topologia recalculada.");
                }
            }
        }
    });

    println!("Nó ativo. Console Admin disponível em http://localhost:28100");
    node.run().await?;
    Ok(())
}

Arquitetura e Componentes

Construído para baixa latência determinística, tolerância a falhas autônoma e pegada de memória mínima.

QUIC Multi-Stream Transport

Sub-streams independentes para controle e dados eliminam bloqueios Head-of-Line. Criptografia TLS 1.3 nativa com autenticação mútua entre nós.

SWIM Gossip & Detecção de Falhas

Algoritmo O(1) com pings indiretos (ping-req) e decaimento exponencial de suspeitas. Isola nós particionados sem tempestades de broadcast.

Consenso Raft Embutido

Consenso via OpenRaft com eleição de líder e replicação de log com snapshots compactos. Zero dependências externas (sem ZooKeeper ou etcd).

Fjall Zero-Copy LSM Storage

Armazenamento em disco baseado em Log-Structured Merge-tree otimizado para gravações rápidas com WAL e particionamento em keyspaces.

Planus FlatBuffers via aaron-build

Compilação automática de schemas no build.rs via aaron-build. Zero ciclos de CPU gastos desserializando dados no tráfego de rede.

Console Admin Vue.js 3

Dashboard SPA embutido diretamente no binário com rust-embed. Canvas de topologia de nós, inspetor de keyspaces e telemetria ao vivo.
